Implement Lagrange Interpolating Polynomial: Develop a Python script to approximate the sine function sin(x) using Lagrange Interpolating Polynomials. This involves creating a function that takes arrays of data points and returns the interpolated value for a given x. Numerical Results and Error Analysis: Use the implemented function to approximate sin(π/8) and calculate the relative error compared to the exact value. This helps in understanding the accuracy of the interpolation method.

Visual Demonstration: Create visual plots to compare the interpolated values with the exact sine values over the interval [0,2π]. This includes generating arrays of interpolated values and plotting them alongside the exact sine function to visually assess the accuracy.

Report Writing: Document the process and results in a LaTeX report.

Overall, the project aims to provide hands-on experience with Lagrange Interpolating Polynomials, enhance understanding of numerical approximation methods, and improve skills in programming, error analysis, and technical reporting.
